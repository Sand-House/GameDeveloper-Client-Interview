
# RVO / NRVO (Return Value Optimization / Named Return Value Optimization)

## 1. 개념

### RVO (Return Value Optimization)
- 함수에서 **임시 객체를 반환할 때** 최적화
- 객체를 **함수 스택이 아닌 호출자 스택에 바로 생성**
- 복사 생성자나 이동 생성자 호출을 생략하여 성능 향상

### NRVO (Named Return Value Optimization)
- 함수 내 **이름이 있는 로컬 변수를 반환할 때** 적용되는 최적화
- 로컬 변수를 호출자 스택에 바로 생성
- 복사/이동 생성자를 호출하지 않아도 됨

---

## 2. 특징

- 둘 다 **복사/이동 생성자 호출 비용을 제거**하는 최적화
- RVO: 임시 객체 반환 시 적용
- NRVO: 이름 있는 로컬 변수 반환 시 적용
- 적용 여부는 **컴파일러 최적화에 따라 달라질 수 있음**
- **포인터 반환**과 같은 경우는 RVO/NRVO 적용 대상이 아님
- **함수 내 반환 경로가 여러 개**이거나, **조건문에 따라 반환 객체가 달라질 때**는 적용되지 않음
---

## 3. 장점

1. **성능 향상**
   - 복사/이동 생성자를 호출하지 않아도 됨
2. **메모리 효율**
   - 임시 객체를 별도로 생성하지 않고 호출자 공간에 바로 생성
3. **이동 의미론과 결합 시 효과 극대화**
   - C++11 이후 이동 생성자와 함께 사용 가능
   - RVO/NRVO가 적용되지 않아도 이동 생성자 호출로 비용 절감 가능

---

## 4. C++03 vs C++11

| 구분 | C++03 | C++11 | RVO/NRVO 적용 |
|------|-------|-------|---------------|
| 함수 반환 객체 | prvalue | prvalue | 호출자 스택에 바로 생성 |
| 이동 의미론 | 없음 | 가능 | 복사/이동 생략 가능 |
| 복사/이동 생성자 | 복사 생성자 호출 | 이동 생성자 호출 가능 | 호출 생략 |
