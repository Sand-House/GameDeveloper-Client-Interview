# C++ 생성자/소멸자 정리

## 1. 생성자(Constructor)
- 객체가 생성될 때 자동으로 호출되는 함수
- 객체를 초기화하는 역할
- 클래스 이름과 동일하며 반환 타입이 없음

### 1-1. 기본 생성자(Default Constructor)
- 매개변수가 없거나 모든 매개변수가 디폴트 값을 가지고 있는 생성자 
- 객체가 생성될 때 초기화 용도로 자동 호출

### 1-2. 복사 생성자(Copy Constructor)
- 기존 객체를 이용해 새 객체를 만들 때 호출
- 원본 객체를 그대로 복제
- 매개변수: `const 클래스&`
- 특징: 원본 객체는 그대로 유지

### 1-3. 이동 생성자(Move Constructor)
- 임시 객체(prvalue)나 소멸될 객체(xvalue)에서 새 객체 생성 시 호출
- 기존 객체의 리소스를 “훔치기” 때문에 복사보다 효율적
- 매개변수: `클래스&&` (rvalue 참조)
- 특징: 원본 객체는 비워지고 새 객체가 리소스를 가져옴
- 사용 시: `std::move`로 lvalue를 rvalue로 캐스팅 필요

### 1-4. 생성자 호출 요약
- 기본 생성자 → 객체 생성 시
- 복사 생성자 → lvalue 객체로 새 객체 생성 시
- 이동 생성자 → rvalue(임시 객체나 std::move)로 새 객체 생성 시

### 1-5. 예시 코드
```
struct Foo {
    vector<int> v;
    Foo() {}
    Foo(const Foo& other) : v(other.v) { cout << "복사 생성자\n"; }
    Foo(Foo&& other) : v(move(other.v)) { cout << "이동 생성자\n"; }
};
```

## 2. 소멸자(Destructor)
- 객체가 사라질 때 자동으로 호출
- 동적 메모리 해제, 리소스 반환 등 정리 역할
- 클래스 이름 앞에 `~`를 붙임
- 특징: 스코프를 벗어나면 자동 호출

---

## 3. 생성자 접근자
- 생성자는 반드시 public일 필요 없음
- 외부에서 객체를 생성하려면 public이어야 함
- private/protected 생성자:
  - private → 외부에서 객체 생성 불가 (싱글톤 패턴 등)
  - protected → 상속받은 클래스에서만 객체 생성 가능

---

## 4. 객체 생성 위치
- **스택 객체**
  - 스코프 내에서 생성
  - 자동 소멸, 빠름, 안전
  - 예: `Foo f;`
- **힙 객체**
  - new로 생성, delete로 소멸
  - 동적 수명, 크기 제한 없음, 느림
  - 예: `Foo* f = new Foo(); delete f;`

---

## 5. 핵심 포인트
1. 복사 생성자 → 원본 객체 복제, 비용 발생  
2. 이동 생성자 → 리소스 이동, 성능 최적화  
3. 생성자는 반환값 없음, 임시 객체는 return 문에서 생성 가능  
4. 스택 객체 → 자동 생성/소멸, 힙 객체 → 수동 관리  
5. 접근자에 따라 객체 생성 가능 여부 결정
